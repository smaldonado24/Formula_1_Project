# Formula_1_Project

Monaco Grand Prix SQL Data Analysis Project

Using PostgreSQL, I designed and implemented a comprehensive database project to analyze historical performance data from the Monaco Grand Prix in Formula One. By applying advanced query writing, data analytics, and data cleaning techniques, I extracted key insights, including:

 • The driver with the most wins at the Monaco Grand Prix.

 • The constructor with the most victories at the Monaco Grand Prix.

 • The driver holding the fastest lap record at the Monaco Grand Prix.

This project showcased my expertise in database design, query optimization, and deriving actionable insights from structured data, while combining my passion for motorsport with technical problem-solving.


Formula One Data Analytics Project

Leveraging Python and Pandas, I developed a data-driven project focused on Formula One racing. The project involved extensive data cleaning, analysis, and visualization to uncover key insights about the sport’s history and performance trends. Through visually engaging charts, I highlighted:

 • The all-time leader in Grand Prix wins.

 • The most successful constructor in Grand Prix history.

 • A detailed analysis of Formula One world champions over the past decade.

This project demonstrated my ability to manage complex datasets, perform analytical tasks, and communicate findings through clear and impactful visualizations. It combines my passion for data science with my interest in Formula One racing.
